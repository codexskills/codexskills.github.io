# CodexSkills Portfolio

Premium personal portfolio for **Deepu Kumar** — AI Agent Developer & Open Source Builder.

## Features

- 3D particle network background (Three.js)
- Aurora gradient mesh shader
- GSAP scroll-triggered animations
- Glassmorphism design system
- Dark theme with neon accents
- 11 sections (Hero, Tech Strip, About, Expertise, Services, Featured, Open Source, Process, Testimonials, Contact, Footer)
- Fully responsive
- SEO optimized
- Accessibility support

## Tech Stack

- Three.js r128 — 3D particles + custom GLSL shader
- GSAP 3.12 — ScrollTrigger, text reveals, counters
- Vanilla CSS — Glassmorphism, gradients, custom properties
