Capabilities

Project types supported

Each type maps to a tailored reference stack with specific recommendations.

Web Application

SaaS, dashboard, e-commerce, landing pages. Full-stack with SSR, API routes, and database.

Bot

Telegram, Discord, and Slack bots with webhook handling, inline keyboards, and async processing.

API / Backend

RESTful APIs, GraphQL endpoints, microservices. Auto-documented with OpenAPI and type-safe.

Mobile Application

Cross-platform (React Native, Flutter) and native (SwiftUI). Push notifications, offline storage.

AI System

RAG pipelines, LLM chatbots, AI agents. Vector databases, embedding models, and prompt orchestration.

CLI Tool

Command-line applications, developer tools, automation scripts. Single-binary or pip/npm distribution.
